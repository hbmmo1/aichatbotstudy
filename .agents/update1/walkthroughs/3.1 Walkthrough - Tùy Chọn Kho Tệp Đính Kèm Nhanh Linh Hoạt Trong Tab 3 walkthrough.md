# Walkthrough - Tùy Chọn Kho Tệp Đính Kèm Nhanh Linh Hoạt Trong Tab 3

Đã hoàn thành xây dựng **Kho Tệp Đính Kèm Nhanh Linh Hoạt (Tab 3 Quick File Bundles)** theo đúng mọi yêu cầu:

---

## 1. 📦 Kiến Trúc 3 Cột Hiện Đại Trong Tab 3 (Quick Scripts):
- **Cột 1 (Trái):** 📋 Danh Sách Mẫu Kịch Bản & Lọc Danh Mục.
- **Cột 2 (Giữa):** 📝 Chi Tiết & Soạn Thảo Mẫu (Nhãn, Câu hỏi, Câu trả lời, Tệp cố định của mẫu, Nút Gửi Zalo/Draft/Hủy).
- **Cột 3 (Phải):** 📦 **KHO TỆP ĐÍNH KÈM NHANH LINH HOẠT (Tree Checklist)**.

---

## 2. ⚡ Các Tính Năng Đột Phá Của Kho Tệp Linh Hoạt:
1. **Tạo nhiều nhóm tệp linh hoạt:**
   - Tạo các nhóm tệp theo nhu cầu (ví dụ: `[Lớp 10]`, `[Lớp 11]`, `[Lớp 12]`, `[PPCT]`, `[Đề Thi 15p]`, `[Khóa Học]`).
   - Tên nhóm và tên tệp hiển thị ngắn gọn (`basename`), tiết kiệm diện tích tối đa để hiển thị được rất nhiều tệp cùng lúc.
2. **Tích chọn linh động (Tree Checklist):**
   - **Click vào Nhóm:** Bật/Tắt `[✓]` chọn toàn bộ các tệp trong nhóm đó.
   - **Click vào từng Tệp:** Bật/Tắt `[✓]` riêng lẻ cho từng tệp.
   - **Kết hợp đa nhóm:** Có thể tích chọn 1 file ở nhóm này, 2 file ở nhóm khác hoặc cả nhóm để gửi cùng lúc.
   - **Đếm số lượng realtime:** Dòng tiêu đề hiển thị ngay `✨ Đang tích: X tệp`.
3. **Thao tác quản lý tiện lợi:**
   - **`➕ Nhóm` / `➕ File` / `📂 Folder`:** Tạo nhóm mới, thêm từng file hoặc nạp cả thư mục vào nhóm.
   - **`▲ Lên` / `▼ Xuống`:** Sắp xếp vị trí thứ tự của nhóm hoặc từng file trong nhóm.
   - **`✏️ Sửa Tên` / `🗑️ Xóa`:** Đổi tên nhóm, đổi tên hiển thị của file hoặc xóa khỏi nhóm.
   - **`☑️ Chọn Hết` / `☐ Bỏ Chọn`:** 1-click chọn tất cả hoặc bỏ chọn tất cả.
   - **`📥 Nạp` / `📤 Xuất`:** Xuất & nạp kho tệp ra file JSON để sao lưu / chuyển máy.
   - **Menu chuột phải:** Hỗ trợ mở file trực tiếp trên Windows hoặc mở thư mục chứa file trong Explorer.
4. **Tự động gộp khi gửi (`🚀 Gửi Vào Zalo`, `Enter`, `F10`):**
   - Hệ thống tự động gộp: **Tệp cố định của mẫu kịch bản** + **Tất cả các tệp đang được tích chọn `[✓]` trong Kho Tệp Linh Hoạt** (tự động loại trừ tệp trùng lặp).
   - Gửi trọn vẹn văn bản câu trả lời + toàn bộ tệp đính kèm vào Zalo PC / UltraViewer / AnyDesk!
