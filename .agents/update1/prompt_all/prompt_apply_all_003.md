# PROMPT ÁP DỤNG DÙNG CHUNG: GIAO DIỆN TAILWIND SLATE DARK/LIGHT MODE

```text
Khi xây dựng hoặc cập nhật giao diện Desktop (Tkinter/CustomTkinter):
1. Hỗ trợ đầy đủ Light Theme (nền trắng #ffffff / Slate-50 #f8fafc, chữ chính #0f172a, điểm nhấn xanh #0284c7).
2. Hỗ trợ đầy đủ Dark Theme (nền Slate-900 #0f172a, chữ chính #f8fafc, điểm nhấn xanh #38bdf8).
3. Tuyệt đối không dùng màu chữ cùng tông với màu nền gây chìm chữ hoặc khó đọc.
4. Quét đệ quy toàn bộ widget con bao gồm cả Canvas để đổi màu đồng bộ tức thì khi người dùng chuyển theme.
```
